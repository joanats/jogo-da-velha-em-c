# 🎮 Jogo da Velha em C

Um projeto desenvolvido em linguagem C para implementar o clássico **Jogo da Velha**, permitindo que dois jogadores disputem uma partida diretamente pelo terminal.

## 📌 Sobre o projeto

Este projeto tem como objetivo praticar os conceitos fundamentais da programação em C, como funções, estruturas condicionais, laços de repetição, manipulação de matrizes e organização do código em diferentes arquivos.

## 🎯 Funcionalidades

- Exibição do tabuleiro no terminal.
- Entrada de jogadas pelos jogadores.
- Alternância entre os jogadores.
- Verificação de vitória.
- Identificação de empate.
- Organização do código em módulos.

## 🛠️ Tecnologias utilizadas

- **Linguagem:** C
- **Compilador:** GCC
- **Controle de versão:** Git e GitHub
